# Umay-6T Data Reproducibility Package

This repository contains the data reproducibility package for the **Umay-6T: Mobility-Resilient Cell Caching for Uninterrupted 6TiSCH Networks** manuscript.

## Commercial Restrictions on Source Code
The core algorithmic implementations of Umay-6T are tightly coupled with proprietary/commercial operating system components developed for specific industrial applications. As a result, the full `Contiki-NG` modified OS tree cannot be released as open-source software due to commercial licensing restrictions.

## Scientific Reproducibility Commitment
To ensure **full scientific transparency and reproducibility** of our results, we provide the following artifacts instead of the proprietary C source code:
1. **Raw Simulation Logs (`raw_logs/`):** The exact `.log` files generated by the Cooja simulator during the evaluation phase.
2. **Mobility Traces (`mobility_traces/`):** The `.dat` files generated by BonnMotion, ensuring the exact same mobility vectors can be evaluated by other researchers.
3. **Automated Parsing & Plotting Scripts (`scripts/`):** Python scripts that parse the raw `.log` files and automatically generate the graphs presented in the manuscript.

This approach guarantees "Data Reproducibility", allowing reviewers and the academic community to verify that our performance claims (PDR, Latency, and Control Overhead) are genuinely derived from extensive experimental simulations.

## How to Verify the Results

To verify the graphs and statistics presented in the manuscript, you can run the provided plotting script over the raw logs.

### Prerequisites
You need Python 3 installed along with `matplotlib`.
```bash
pip install matplotlib
```

### Running the Parsing Script
Navigate to the `scripts` directory and run the `plot_results.py` script:

```bash
cd scripts
python3 plot_results.py --logs_dir ../raw_logs --output_dir .
```

### Expected Output
The script will output the average Packet Delivery Ratio (PDR), End-to-End Latency, and 6P Control Overhead to the console, and it will generate a `reproducibility_plots.pdf` file containing the bar charts mirroring the manuscript's findings.
